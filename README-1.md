## 📌 Project Overview

**Functional Treat -- Data Analyzer and Transformer** is a menu-driven
Python application that demonstrates practical data analysis, data
transformation, and functional programming concepts.

The project works with **1D and 2D data** and provides options for
displaying data, calculating statistics, finding duplicate and unique
values, filtering and transforming values, sorting data, demonstrating
`*args` and `**kwargs`, and calculating factorial using recursion.

## 🎯 Objectives

-   Work with 1D and 2D data.
-   Perform basic data analysis and transformation.
-   Calculate minimum, maximum, sum, and average.
-   Find duplicate and unique values.
-   Demonstrate lambda functions with `filter()` and `map()`.
-   Demonstrate recursion through factorial.
-   Demonstrate `*args` and `**kwargs`.
-   Build an interactive menu-driven Python program.

## 🔄 How the Program Works

### 1. Input 1D Data

The user selects option `1` and enters numbers separated by spaces.

``` text
Enter your choice : 1
Enter numbers separated by space: 11 22 33 44 55
1D Data stored successfully!
```

### 2. Input 2D Data

The user selects option `2`, enters rows and columns, and then enters
elements row by row.

``` text
Enter your choice : 2
Enter number of rows: 3
Enter number of columns: 3

Row 1: 10 20 30
Row 2: 40 50 60
Row 3: 70 80 90

2D Data stored successfully!
```

### 3. Display Data

Example:

``` text
10   20   30
40   50   60
70   80   90
```

### 4. Data Summary

For the sample dataset:

``` text
Total Elements : 9
Minimum Value  : 10
Maximum Value  : 90
Sum            : 450
Average        : 50.0
```

### 5. Duplicate Values

The program checks whether any values occur more than once.

``` text
No duplicate values found.
```

### 6. Unique Values

``` text
Unique Values : [10, 20, 30, 40, 50, 60, 70, 80, 90]
```

### 7. `*args`

The project demonstrates receiving multiple positional values:

``` text
Values received using *args:
10 20 30 40 50
```

### 8. `**kwargs`

The project demonstrates receiving multiple keyword arguments using
`**kwargs`.

### 9. Factorial Using Recursion

Example shown in the project:

``` text
Enter your choice : 10
Enter a number : 33
Factorial = 868331761881188649551819440128000000000
```

### 10. Filter Using Lambda + `filter()`

Example:

``` text
Enter limit_value value: 44
Filtered Data : [50, 60, 70, 80, 90]
```

### 11. Square Using Lambda + `map()`

Example:

``` text
Squared Values : [100, 400, 900, 1600, 2500, 3600, 4900, 6400, 8100]
```

### 12. Dataset Statistics

``` text
Minimum : 10
Maximum : 90
Sum     : 450
Average : 50.0
```
